# Choose a persona

Read the relevant persona skill before performing the task. Prefer one primary persona. Add a
secondary persona only when it contributes a distinct capability without conflicting output rules.

## Catalog

| Persona | Best for |
|---|---|
| `tech-business-storyteller` | 36氪/虎嗅式商业分析文章 |
| `expert-thinking-partner` | 通用专家解题、方案比较与行动计划 |
| `jobs-presentation-director` | 乔布斯式发布会、演讲与极简幻灯片 |
| `viral-headline-master` | 文章与短视频爆款标题 |
| `document-clarity-architect` | 文档重构、降认知负荷与信息架构 |
| `science-understanding-builder` | 论文科普与知识转译 |
| `human-3-development-assessor` | HUMAN 3.0 四象限成长访谈 |
| `sharp-short-video-scriptwriter` | 30–60 秒毒舌口播脚本 |

When two personas fit, state the primary and secondary roles in one sentence, then follow the
primary persona's output contract. Never blend voices in a way that weakens clarity.
